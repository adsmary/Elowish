# ✨ Elowish

**Elowish — Every wish has a story.**

Elowish é um protótipo de uma plataforma digital criada para transformar sonhos, desejos e objetivos em experiências especiais. Com uma interface mágica e personalizável, permite organizar metas, registrar memórias em um diário digital, criar listas de desejos e acompanhar conquistas.

Desenvolvido como projeto de portfólio, o Elowish combina organização pessoal, criatividade e uma estética dreamy com elementos de glassmorphism.

🌙 **Um espaço para registrar sonhos, acompanhar jornadas e celebrar cada conquista.**
